SECURITY OPERATIONS

My journey into cybersecurity began with my academic foundation in Network Engineering at Universiti Malaysia Sabah. Studying computer networks helped me understand how devices communicate, how network protocols operate, and how information moves across interconnected systems. Over time, I became increasingly interested in understanding not only how networks function, but also how they can be monitored, analysed, and secured.

Currently, as a Master of Cybersecurity student at Universiti Malaya, I am expanding my technical knowledge through coursework, practical assignments, and cybersecurity research. One of my key interests is security operations, particularly the role of network visibility and traffic analysis in identifying potential security threats.

A significant part of my learning has involved practical network programming using Python and Scapy. In my WQE7002 coursework, I developed a network device discovery tool using Address Resolution Protocol (ARP). This project explored how authorised hosts could be identified through network communication and how results could be recorded systematically. It also introduced important considerations such as defining authorised scanning scopes, handling network responses, and validating observations using independent tools.

Another practical project involved implementing a TCP SYN port scanner using Python and Scapy. This assignment provided an opportunity to examine TCP communication at the packet level and understand how different responses can indicate whether a port is open, closed, or inconclusive. Packet captures and Nmap validation were used to support the recorded observations. These exercises reinforced the importance of interpreting network evidence carefully rather than making assumptions from incomplete responses.

My previous undergraduate research in lightweight cryptography also contributed to my understanding of cybersecurity. Through a comparative study of stream ciphers for resource-constrained IoT devices, I explored the relationship between cryptographic performance, memory limitations, and hardware capabilities. This research demonstrated that security solutions must consider the practical limitations of the systems in which they operate.

An important lesson from these experiences is that technical results require careful validation and interpretation. A network scan may produce useful observations, but those observations must be understood within the boundaries of the experiment. Similarly, a cryptographic algorithm may perform efficiently on one hardware platform without necessarily being the most appropriate choice for another.

Although I have developed a foundation in networking and practical security tools, I recognise that security operations involve additional skills beyond network scanning. Areas such as security event correlation, incident investigation, threat intelligence, and structured incident response remain important subjects for further development.

My next learning objective is to strengthen my understanding of SOC workflows through practical log analysis and security monitoring exercises. I aim to complete a documented security investigation lab within the next three months, including evidence collection, event interpretation, and a written incident summary.

As I continue my master's studies, I hope to connect theoretical knowledge with practical cybersecurity experience and develop the analytical skills required to contribute effectively to security operations.
